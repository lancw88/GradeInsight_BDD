# User Story (已修正): 成績自動調整規則

## 基本信息
- **ID**: US-009-revised
- **版本**: Release_2
- **狀態**: Pending
- **優先級**: High

## User Story 描述

**作為** 授課教師

**我想要** 能夠定義和應用成績自動調整規則，例如根據出勤率自動扣分或獎勵

**以便於** 自動應用評分政策，提高評分的一致性和效率

## 接受標準

1. [ ] 支持定義調整規則（如"缺勤3次以上扣5分"）
2. [ ] 支持多種規則類型：扣分規則、獎勵規則、比例調整規則
3. [ ] 應用規則前提供預覽，顯示會影響哪些學生和變化範圍
4. [ ] 規則應用是可追蹤的，記錄哪個規則進行了調整
5. [ ] 支持撤銷特定規則的應用
6. [ ] 規則應用後不應再次自動應用（防止重複）
7. [ ] 支持保存和復用規則模板

## 相關資訊

**衝突**: 無

**依賴**: US-001（匯入學生成績）、US-004（應用自訂評分方案）

**備註**: 自動調整應得到人工確認，不應在未經授權的情況下自動執行

## 修正說明

此版本已從原US-009修正，解決的問題如下：
- ✅ 移除了相互矛盾的"既允許修改又完全鎖定"的要求
- ✅ 明確了規則應用的範圍和流程
- ✅ 強調了可追蹤性和可撤銷性
- ✅ 明確說明應用前需要預覽確認
- ✅ 將自動調整和成績鎖定分為獨立需求

3. **不可達成的目標**：
   - 無法既允許自動修改又完全鎖定成績
   - 無法既快速更正錯誤又絕對禁止修改

### 改進建議

應該分為兩個獨立的User Story：
1. **自動成績調整Story**：定義在什麼條件下允許調整，調整流程
2. **成績版本控制Story**：定義成績審定後如何保護，修改記錄如何追蹤

原始需求必須明確：
- 成績在什麼階段可以修改
- 誰有權修改成績
- 修改成績的審批流程
- 成績最終如何鎖定
